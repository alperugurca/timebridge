# TimeBridge

- [https://alperugurca.github.io/timebridge/](https://alperugurca.github.io/timebridge/)
- [https://timebridge.sourceforge.io/](https://timebridge.sourceforge.io/)
- [https://sourceforge.net/projects/timebridge/](https://sourceforge.net/projects/timebridge/)

TimeBridge is a simple world clock for comparing time zones. Choose a date and location to view times and countdowns.

Open `index.html` in a modern web browser to use the site. No build step or installation is required.
